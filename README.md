# HTML-Pet

HTML-Pet is a browser-based pixel slime companion experiment. Its intended scope includes pet care and progression through food, farming and equipment. Treat playability, progress recovery and offline behavior as prototype qualification work.

This is the independent browser project. Keep it separate from native PC-Pet and LFS companion projects unless the owner explicitly requests shared assets or behavior.

## Start a task

Read [AGENTS.md](AGENTS.md), identify the requested outcome and inspect the smallest relevant source area. Distinguish an observation of code from behavior demonstrated in a browser. Keep unrelated feature expansion separate from the task being addressed.

For a change involving progression or saved state, retain evidence for the intended outcome:

- A repeatable play sequence earns the agreed reward under the intended health and feeding rules.
- Restart preserves the state that is supposed to persist.
- Invalid saves produce a visible recovery outcome.
- Offline progress follows an agreed timing rule and cap.

The owner’s intended reward and offline-balance rules must be established before expanding those systems. Documentation and bounded investigation can continue while those product decisions remain pending. A source review alone does not close these acceptance items.
